# Sideplate Studio

A local-first studio for making AI-animated series, built for one creator on a
zero budget. Instead of scattered folders and lost prompts, every character,
set, voice and track lives in one organised library, saved as plain files on
your own computer.

**What it does today (Phase 1):**
- **Cast and sets:** generate by trial and error, keep every attempt, cast a
  winner, and build reference packs (views and expressions) that keep a
  character consistent across episodes and art styles.
- **Rights tracking:** every image, track and voice clip records where it came
  from and whether its rights have been checked. A license guard blocks
  non-commercial models and unreviewed assets from monetized projects.
- **Free GPU batches:** queue jobs all week, export one bundle, run the
  included notebook on Kaggle's free GPU, and import the results.
- **Safe by design:** approved images are never overwritten, deletes go to a
  restorable trash, and one-click backups are verified file by file.

**Coming next:** project-first navigation with a shared universal library,
shot lists, a draft-first editing pipeline, a Voice Lab, and per-shot video
generation.

Runs on macOS and Windows with Node.js 18 or newer. No npm install needed.
